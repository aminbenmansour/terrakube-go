# Contributing

Terrakube Go is a drop-in-compatible rewrite of Terrakube. Upstream behavior
wins; see `docs/compat.md`.

## Setup

- Go 1.27+
- Podman and `jq`
- `export PATH=$PATH:/usr/local/go/bin` if Go is not already on `PATH`

```bash
make services-up
make db-migrate
make run-api
```

## Checks

```bash
make check        # gofmt, go vet, go test
make test-race    # race detector
make build        # all binaries
make smoke        # requires a running API and jq
```

## Generated code

`internal/store/*.sql.go` is generated by sqlc. Edit the SQL in
`internal/store/queries/`, then run `make generate`. Install the pinned tool
with `make tools` if needed. Never edit generated files by hand.

Migrations are append-only. Add a new numbered file under `migrations/`; do not
edit an applied migration.

## Compatibility

Read `docs/compat.md` before changing an endpoint, payload, status code or
table/column. Update the document when the observed contract changes.

## Commits and pull requests

Use conventional commit subjects and keep changes focused. This repository
uses stacked PRs; see `.opencode/skills/stacked-prs/SKILL.md`. Never push
`main`, force-push shared history, or merge a PR without approval.
